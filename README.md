# リンク本棚

リンクを本の表紙のように並べて整理する Web アプリです。スマホでも PC でも使えて、ホーム画面に追加するとアプリのように起動できます。

## できること

- **リンクの追加・編集・削除**(削除は 2 回押すと確定します)
- **フォルダー**
  - 右下の「＋」から作れます。作ったものは、今開いている場所に入ります
  - フォルダーの中にフォルダーを作れます(何段でも)
  - フォルダーの箱には、中のリンクの表紙が最大 3 枚重なって表示されます
  - 上部の「本棚 › 料理 › 和食」をタップすると、その階層に戻れます。スマホの「戻る」操作でも戻れます
  - リンクやフォルダーを別の場所に移すときは、✎ から編集画面を開き、「フォルダー」または「入れる場所」で選びます
  - 中身のあるフォルダーを削除するときは、「中身を1つ上に出す」か「中身ごと削除」かを選べます
- **表紙は 3 種類**
  - サイトの画像(自動):リンク先のサムネイル画像を表紙にします。サムネイルがないサイトは、ページのスクリーンショットを使います。どちらも表示できないときは色の表紙になります
  - 色の表紙:名前とサイト名入りの表紙です。8 色から選べます
  - 画像を選ぶ:手持ちの画像を 2:3 に切り抜いて表紙にします(ドラッグで位置、スライダーで拡大を調整)
- 名前を空欄にすると、サイトのタイトルが自動で入ります
- 表紙右上の ☆ をタップするとお気に入り(★)になります
- **絞り込み**:すべて/お気に入り。名前・URL での検索もできます(検索とお気に入りは全フォルダーが対象)
- **並び替え**:追加が新しい順、追加が古い順、名前 あ→ん、名前 ん→あ、お気に入りを先頭
- **バックアップ**:右上の「…」から保存・復元できます。別の端末にデータを移すときに使います

## 注意点

- データは開いた端末のブラウザ内に保存されます。スマホと PC の自動同期はありません
- サイト画像の自動取得には、次の無料サービスを使っています
  - サムネイルとタイトルの取得:[microlink](https://microlink.io/)(無料枠は 1 日 50 回まで。一度取得した表紙は保存して使い回します)
  - スクリーンショット:[thum.io](https://www.thum.io/)
- 画像の表紙は端末の保存容量を使います。容量がいっぱいになると保存できなくなるので、その場合は画像の表紙を減らしてください

## 公開手順(GitHub Pages)

1. GitHub で「＋」→「New repository」を開き、名前を `link-shelf`、Public にして作成します
2. 「uploading an existing file」を開き、このフォルダーの**中身**をまとめてドラッグ&ドロップします
   - `js` フォルダーも必ず含めてください(ファイル選択の画面ではフォルダーを選べないため、ドラッグ&ドロップを使います)
   - `index.html` がリポジトリの一番上に来るようにします。`link-shelf` フォルダーごと入れると開けなくなります
3. 「Commit changes」を押します
4. Settings → Pages で、Source を「Deploy from a branch」、Branch を `main`、フォルダーを `/ (root)` にして Save を押します
5. 1〜5 分後に `https://ユーザー名.github.io/link-shelf/` で開けるようになります
6. スマホでその URL を開き、ホーム画面に追加します
   - iPhone:Safari の共有ボタン →「ホーム画面に追加」
   - Android:Chrome のメニュー →「ホーム画面に追加」

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みとデザイン |
| `js/app.js` | 画面の表示と操作 |
| `js/store.js` | データの管理(リンク・フォルダー・並び替え・バックアップ) |
| `js/cover.js` | 表紙(色、サイト画像の取得、画像の切り抜き) |
| `sw.js` | オフラインでも画面を開くための仕組み |
| `manifest.json` | ホーム画面に追加するための設定 |
| `icon-*.png` | アプリのアイコン |
